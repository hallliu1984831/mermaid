FluxCD 不是 Git 直接到 Pod

发布问题要沿着链路看：哪一层还是旧的，问题通常就卡在哪一层附近。

GitRepository -> Kustomization -> HelmRepository
-> HelmChart -> HelmRelease -> Deployment / Pod
